# Glossary of Core Terms
 
This glossary defines the vocabulary used throughout the WindConfig AI Copilot knowledge base. All names, codes and figures are fictional and exist only for demonstration purposes.
 
## Structure terms
 
**Contract.** The top-level record that groups service arrangements for a set of turbines. A contract can have several availability configurations.
 
**Availability Configuration.** A set of rules describing how availability is calculated for a given contract over a given date range. Each configuration is identified by a GUID, a globally unique identifier generated by the system.
 
**Version.** Every configuration has numbered versions. A version is in exactly one of three states: *draft*, *published* or *archived*. Only one published version may exist per configuration.
 
**Draft.** A working version that may be incomplete. Drafts can be deleted.
 
**Published.** A complete, validated version that is in force. A published configuration cannot be deleted.
 
**Archived.** A version kept for history that is no longer the current one.
 
**Readiness check.** The backend validation that decides whether a version may be published. The AI Copilot never makes this decision; it only explains the rules.
 
## Calculation terms
 
**Calculation type.** The family of availability measure: TBA (Time-Based Availability), YBA (Yield-Based Availability) or RBA (Revenue-Based Availability).
 
**Formula.** The specific expression used to compute availability. A formula must match the configuration's calculation type.
 
**Period hours.** The total number of hours in the evaluated period.
 
**Excluded time.** Time that is removed from the calculation, for example because a variant says it should not count.
 
**Potential yield / Actual yield / Lost yield.** The energy a turbine could have produced, the energy it did produce, and the energy that was not produced because of unavailability.
 
**Potential revenue / Actual revenue / Lost revenue.** The yield terms expressed in currency units.
 
## Wind terms
 
**Low wind variant.** A setting that decides how periods of very low wind are treated: LW_EXCLUDE_BELOW_CUT_IN, LW_COUNT_AS_AVAILABLE or LW_PRO_RATA_POWER_CURVE.
 
**High wind variant.** A setting that decides how periods of very high wind are treated: HW_EXCLUDE_ABOVE_CUT_OUT, HW_COUNT_AS_UNAVAILABLE or HW_STORM_GRACE_WINDOW.
 
## Alarm terms
 
**Alarm category.** A group of alarms. GRID (Grid interruption) and MAINT (Planned maintenance) are required; WX (Weather event) is optional.
 
**Alarm.** An individual event type inside a category, such as GRID_LOSS or SERVICE.
 
## Other terms
 
**Turbine code.** A contract-specific label from T01 to T10. The same code in two different contracts refers to two different turbines.
 
**Park availability.** A numeric value on the configuration that must lie between 0 and 100.
